# Releasing

Two repos: the main repo holds the source; [`gianniacquisto/homebrew-tap`](https://github.com/gianniacquisto/homebrew-tap) holds the [Homebrew cask](https://github.com/gianniacquisto/homebrew-tap/blob/main/Casks/tandem.rb) that installs the prebuilt app. brew only reads taps from its fixed tap directory, so on any dev machine the working copy is wherever brew keeps the clone — `brew tap gianniacquisto/tap` creates it at `$(brew --prefix)/Library/Taps/gianniacquisto/homebrew-tap`. That directory is an ordinary git clone of the tap repo: branch, commit, and push from there (`brew update` keeps it current).

To cut a release:

1. Cut the release on the integration branch and move the release line to it: `git tag v0.6.0 dev && git push origin v0.6.0 dev:main`. `dev` is where merges land; `main` is the release line — its head is always the latest tag, and it moves only by this fast-forward ([ADR 0019](adr/0019-integration-branch.md)).
2. The [Release workflow](https://github.com/gianniacquisto/tandem/blob/dev/.github/workflows/release.yml) runs the test suite, builds and verifies the artifact, and publishes the GitHub release for the tag with `Tandem-<version>.zip` and `SHA256SUMS` attached. It also runs on pull requests — build-and-verify only, never publishing — so a release can be dry-run on a PR. Re-pushing the same tag re-cuts the release. The release notes say "tag on dev, move main", so the shipped build and the release line read as one act.
3. The tap's `brew bump` workflow livechecks the release assets and opens a bump PR for the single cask file with the artifact's real sha256 — merging it is the whole release. It needs the tap's `HOMEBREW_GITHUB_API_TOKEN` secret (a token with `repo` scope) — without a working token the run fails after pushing the bump branch, so the PR has to be opened by hand.
4. If bumping by hand, verify before pushing: `brew style Casks/tandem.rb && brew audit --cask --strict gianniacquisto/tap/tandem`.
5. Users get it with `brew update && brew upgrade --cask gianniacquisto/tap/tandem`.

Always spell the tap's cask out in full. The token is `tandem`, which collides with Homebrew's unrelated `tandem` (tandem.chat, 348 MB); the Caskroom is keyed by token, so a bare `brew upgrade --cask tandem` resolves core's cask against this tap's files and installs *that* app over this one — and `brew outdated --cask` offers its version as an upgrade forever. Renaming the token is the only real fix; until then, every user-facing command carries the tap prefix (installing with `brew install --cask gianniacquisto/tap/tandem` from the README is safe).
