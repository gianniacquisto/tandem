# Screenshots

The app, photographed. Every picture here is the running app's own window,
captured by a spec.

The screenshot rig is cut (CUT-2): `app/shots/`, the Playwright suite, the
publish script and the CI job are gone, and nothing regenerates these files.
They are kept as documentation of the faces at the time they were shot, and the
root `README.md` still points at them.
