# Screenshots

The board and its notes, photographed before the cut. Every picture here is a
running build's own window, captured by a spec.

The screenshot rig is cut (CUT-2): the renderer's Playwright suite, the publish
script and the CI job are gone, and nothing regenerates these files. The
catalogue is a historical record, not a product surface, and the root
`README.md` no longer points at it. Picture evidence for a pull request rides a
scratch attachment, never this folder.
