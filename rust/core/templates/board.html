{#- An open sheet is the human's: a store change must not re-draw the root under their cursor, so the change stream pauses while a sheet is on screen. The pause is the document: a card's link navigates to the sheet's own page, which the shell draws without `sse-connect`. A swap would draw the sheet inside the body already on screen, whose stream stays connected and replaces the sheet on the next change, so nothing here swaps a sheet in. The root keeps `hx-trigger` either way: htmx's default for `hx-get` with no `hx-trigger` is `click`, so an absent attribute is not "no trigger", it is "refetch the board on every click inside the sheet", which dismisses it. -#}
